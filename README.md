# שאבעס מרקט – אפליקציית ניהול עובדים

## מה יש כאן
| קובץ | מה הוא עושה |
|---|---|
| `app.js` | כל המסכים של האפליקציה |
| `store-cloud.js` | החיבור למאגר הנתונים המשותף (Firebase) |
| `store-local.js` | מצב דמו עם נתוני דוגמה |
| `firebase-config.js` | פרטי פרויקט Firebase בשם dalpak |
| `firestore.rules` | כללי האבטחה: מי רשאי לקרוא ולשנות מה |
| `.github/workflows/build-apk.yml` | בונה APK אוטומטית בכל עדכון |

מאגר הנתונים: Firestore בתל אביב (me-west1), בתוכנית החינמית.

## עדכונים אוטומטיים
האפליקציה עצמה מתפרסמת ב-https://nn0548444087-creator.github.io/dalpak/ וה-APK רק טוען אותה משם.
כל שינוי בקוד מתפרסם אוטומטית תוך כמה דקות, וכל העובדים רואים אותו בפתיחה הבאה של האפליקציה, בלי להתקין שום דבר.
את אותה כתובת אפשר לפתוח גם בדפדפן, למשל באייפון.

## הורדת ה-APK
לשונית **Actions** ← הריצה האחרונה עם ✓ ירוק ← למטה ב-**Artifacts** מורידים את `dalpak-apk` (קובץ ZIP שבתוכו `app-debug.apk`).
את ה-APK מתקינים פעם אחת בלבד. צריך APK חדש רק אם משנים את שם האפליקציה, את האייקון או את הכתובת שלה.

## התקנה בטלפונים
1. שולחים את `app-debug.apk` לטלפון (וואטסאפ לעצמכם, מייל או Google Drive).
2. פותחים את הקובץ ← מאשרים **התקנה ממקורות לא ידועים** ← **התקן**.
3. **בפעם הראשונה** (בטלפון של המנהל) מופיע מסך **הגדרה ראשונית**: שם, טלפון, מספר עובד וסיסמת מנהל. הוא מופיע פעם אחת בלבד לכל החנות.
4. ב**ניהול חנות** מוסיפים עובדים עם טלפון ומספר עובד, ושולחים להם את אותו APK.
5. כל עובד נכנס עם הטלפון שלו ומספר העובד שלו.

## חשוב לדעת
- **אבטחה:** ההרשאות נאכפות בשרת. גם מי שמשנה את האפליקציה לא יוכל לראות מלאי נעול, לאשר לעצמו שעות או להיכנס כמנהל בלי הסיסמה.
- **12 שעות ו-1 לחודש:** ההתראה על משמרת פתוחה והסיכום החודשי מחושבים כשהמנהל פותח את האפליקציה. אין התראת דחיפה כשהאפליקציה סגורה (לזה צריך Cloud Functions ותוכנית בתשלום).
- **שעה בטלפון:** החתמה נדחית אם השעה בטלפון רחוקה ביותר מ-5 דקות מהשעה האמיתית.
- **גרסת debug:** מתאימה להתקנה ישירה. לפרסום ב-Google Play צריך גרסה חתומה (AAB).
- **התקנה מחדש:** אם מוחקים ומתקינים מחדש, הנתונים לא נמחקים כי הם בענן. צריך רק להתחבר שוב עם טלפון ומספר עובד.
- **בלי אינטרנט:** האפליקציה מציגה מסך "אין חיבור לאינטרנט" עם כפתור לנסות שוב.
